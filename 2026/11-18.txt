rsarv3006, the param being named arena implies that the function will leak memory if an arena is not used (std.process.Args.toSlice is a good example). The param being named gpa (which stands for "general purpose allocator") effectively means you can use whatever allocator you want, the function will do the necessary cleanup to avoid any leaks
