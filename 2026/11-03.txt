mamu, `-femit-docs` still exists in 0.17.x, but note that it's a `zig build-exe`, `zig build-lib`, etc flag, not a build system flag. If you're using the build system you probably want `Step.Compile.getEmittedDocs()`. Example from zig's build.zig: https://codeberg.org/ziglang/zig/src/commit/4330e71feacbf8ecdf0cf133a976a8d863279ead/build.zig#L58-L75
